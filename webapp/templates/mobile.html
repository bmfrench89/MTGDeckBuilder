Use this on your phone

It installs to your home screen and opens full-screen, like an app. No store, no APK — the page below is the app.
1 · The address to open on your phone
{% if lan %}
http://{{ lan }}:{{ port }}

Type that into Chrome on your phone. Both devices must be on the same Wi-Fi, and this computer has to stay awake with the server running.

{% else %}

The server is bound to localhost, so your phone can't reach it yet.

Start it with webapp\run.bat (Windows) or ./webapp/run.sh — those set MTG_HOST=0.0.0.0, which is what allows other devices on your network in. Then reload this page.

{% endif %}
2 · Install it to the home screen

Android (Chrome): tap ⋮ → Add to Home screen → Install. You get an icon that opens without browser chrome.

iPhone (Safari): tap Share → Add to Home Screen. It must be Safari — Chrome on iOS can't install web apps.

Long-press the installed icon for shortcuts straight to Collection, Build Next and Wishlist.

3 · What works, and what doesn't
  • Everything works while this computer is on and running the server — dashboards, the card panel, optimizing, editing decks, the collection grid.
  • Card images come straight from Scryfall's CDN, so they load on any connection.
  • Offline it shows an honest error, not a stale deck. Your decks change every time you optimize; a cached copy would tell you the wrong 100 cards.
  • Away from home? This only works on your own Wi-Fi. A tunnel (cloudflared tunnel --url http://localhost:{{ port }}) gives you a temporary public HTTPS link — but that exposes your collection and prices, so treat it as short-lived.

Why not a real APK? An installable Android package would either be a browser pointed at this same address (identical to the above, plus a build system), or would need the app hosted publicly over HTTPS. See docs/mobile.md.
