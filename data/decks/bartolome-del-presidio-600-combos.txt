# Note: the command zone. Pair any "aura/enchantment that returns the creature when it

# Note: and the two cards loop forever for zero mana. 44 such two-card engines exist here.
# Note: Each engine + any death-drain payoff (Zulaport Cutthroat, Bastion of Remembrance,
# Note: Marionette Apprentice, Agent of the Iron Throne, Ninja Teen, Scavenger's Talent L2)
# Note: is a kill. Dimir House Guard is a second free sac outlet for the creature half.
# Note: RETURNERS: Sun Titan, Angel of Indemnity, Shepherd of the Cosmos, Redemption Choir,
# Note: Brotherhood Outcast, Danitha Benalia's Hope, Boonweaver Giant.
# Note: RECURSION AURAS: Angelic Renewal, Fungal Fortitude, Minion's Return, Changing
# Note: Loyalty, Kaya's Ghostform, Necrogen Communion, Gift of Immortality.
# Note: Boonweaver Giant tutors its own aura out of the LIBRARY — it is a one-card engine.
# Note: Hard stops: Rest in Peace / Grafdigger's Cage / Soulless Jailer turn every loop off.
