# Treasure census — verified verbatim from Scryfall, 2026-08-21
#
# HOW THIS WAS MADE. The player asked for a Treasure deck. Rather than
# recognising treasure cards by name — which would have missed Relic Retriever,
# Stark Industries Executive, Currency Converter, The Misty Mountains Cold and
# most of this file — every one of the collection's 2,776 non-basic cards was
# put through `carddb.py --verify` on a GitHub runner (deck-verify.yml, runs
# 32508278331 / 32508971642 / 32509059736 / 32509085226 / 32509119407 and one
# workflow_dispatch), and the resulting verbatim oracle text was matched for the
# mechanics below. 2,776 of 2,776 cards were read. Nothing here is from memory.
#
# WHAT IT IS FOR. Grounding rule #2 says count the pool. This is the count, with
# the text that justifies each entry, so a future session does not have to
# re-run 2,776 Scryfall lookups to answer "does this collection do Treasures?"
#
# THE ANSWER: yes. 57 owned cards create Treasure tokens.
#
# Reminder text in parentheses was used to EXCLUDE matches, not include them —
# a card that only mentions Treasure in a reminder clause is not a producer.
#
# REVALIDATED 2026-08-21 (second model, independent classifier): all counts
# reproduced — 57 producers, 33 mono-R / 42 Rakdos / 37 Boros legal, 3 alt-wins,
# 4 symmetric pingers. One repair: "Dori, Bearer of Friends" appeared here under
# a GitHub-Actions log-masked name ("Dori, *** Friends"); the true name is
# restored from the collection snapshot and EDHREC field data, which both carry
# it. Its oracle text was unaffected. Two further pinger-shaped cards (Cave-In,
# Gangrenous Zombies) were checked against the Smaug the Impenetrable loop and
# also fail — one-shot sorcery and self-sacrifice respectively — so the
# one-card-away verdict stands against six candidates, not four.
