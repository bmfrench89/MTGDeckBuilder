# Source: deck-verify.yml run 32612450375 (job 97127502778), 2026-08-23.
# 43 lands queued, 43 resolved, 0 UNVERIFIED.
#
# WHY: the pivot research claimed a free-pool Mardu manabase clears Karsten's ~23
# target in all three colours — W 24 / B 28 / R 32 — by counting the "spend-restricted"
# lands back in "because this is an Angel/Demon/Dragon deck". The text below refutes
# that. Four of the five restricted lands are restricted to types a Kaalia deck does
# not play:
#
#   Avengers Tower          any colour only for a HERO spell
#   Villainous Hideout      any colour only for a VILLAIN spell
#   Castle Doom             any colour only for an ARTIFACT spell
#   Jasmine Dragon Tea Shop any colour only for an ALLY spell
#
# In a Kaalia deck all four are colourless lands. This is the SAME failure the
# Ur-Dragon mana audit caught on 2026-08-20, when Villainous Hideout was cut for
# exactly this reason — the flag heuristic scores them as five-colour fixing and the
# text says otherwise. Plaza of Heroes is the one that survives the check: it is
# restricted to LEGENDARY spells, and this pool's cheat targets include a dozen
# legends plus Kaalia herself. Study Hall, Henge of Ramos, Baxter Building, Rumble
# Arena and Rhystic Cave all charge extra mana or let an opponent fizzle them.
#
# The honest Mardu source count is therefore the UNRESTRICTED one: W 20 / B 24 / R 28
# against a ~23 target — black and red clear, white does not. Still far better than the
# Ur-Dragon's five-of-five misses, but not "all three clear".
